# M1 visual assets

The M1 frontend uses these CC0 assets. They can be redistributed with the project.

| Files | Source | License | Use |
|---|---|---|---|
| `apps/web/public/assets/characters/astronaut.png` | [Top Down Astronaut Animated, OpenGameArt](https://opengameart.org/content/top-down-astronaut-animated) | CC0 | Player and dummy character art; motion is applied in Phaser. |
| `apps/web/public/assets/ui/key-*.svg` | [Input Prompts, Kenney](https://kenney.nl/assets/input-prompts) | CC0 | WASD controls in the HUD. |

The shipping containers, floor, bases, shadows, and HUD shapes are rendered in Phaser or CSS. No restricted third-party art is included. The score and timer displayed in M1 are static prototype values; live match state is outside this milestone.
