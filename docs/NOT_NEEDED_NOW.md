# Not Needed Now

## Voice-speaking indicators

Do not add visual indicators showing which player is currently speaking. The current game does not need a speaker icon over characters or a speaking list in the voice dock. Keep this out of active implementation work unless the product decision changes.

## Contextual in-match hints

Do not add just-in-time tutorial prompts during a match for now. The landing-page field guide already explains the controls and core mechanics; revisit in-match hints only if playtest feedback shows players need them.

## Key remapping

Keep the current fixed keyboard controls. Do not add a key-binding screen or custom control mapping for now.

## Broad UI contrast pass

Keep the current visual palette and contrast treatment. Do not add a separate high-contrast mode or redesign the UI colors for now.

## Separate volume controls

Keep the existing voice mute/deafen controls. Do not add separate game and voice volume sliders for now.

## Reduced-motion settings for game effects

Do not extend reduced-motion handling to Phaser tag, raid, particle, or character feedback animations for now. Keep the current game feedback effects as authored; revisit only if player feedback or accessibility testing calls for it. The tutorial page turn and radar pulse already honor the browser's reduced-motion preference.
